## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  gemini-3.5-flash-lite に聞いたところ、「AIの活用レベル（利用・カスタマイズ・開発）」か「難易度別の3コース（Basic / Standard / Advanced）」のどちらかだろう、という推測を並べた。最後は「Slackのログや講師に確認を」で締めていた。
- 用語集の正しい意味と比べて気づいたこと：
  正しくは「基礎・実装・発展」の3段階で、どれか1つやれば完了。名前は外れているのに、「難易度を選んで提出する形式かもしれない」という部分は半分くらい当たっていて、それっぽさが逆に怖いと思った。
  ほかの質問も試した。「lecNN-start タグ」は、コードの中に入れる目印のコメントだと説明していて、`lecNN-end` もあるかもしれないと付け足していた（どちらも根拠なし）。「第2回では何を学ぶか」だけは、情報を持っていないと素直に答えた。同じ「知らない」でも、答え方が質問によって違った。
- 表示できたトークン数（入力 / 出力）：
  「LoRAとは何ですか？」で 7 / 527。「3レベル」の質問で 21 / 約500（回によって 370〜670 くらい）。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  「AIE2026の講座の宿題にある「3レベル」とは何ですか？」を、次の4条件で3回ずつ（計12回）聞いた。
  - gemini-3.5-flash-lite（temperature 既定）
  - gemini-3.5-flash（temperature 既定）
  - gemini-3.5-flash-lite（temperature 0.0）
  - gemini-3.5-flash-lite（temperature 1.5）

  毎回手で打つのが面倒だったので、`app/ask.py` の呼び出し部分を `generate(question, model, temperature)` に切り出した。条件を並べて表を出すスクリプトは `lectures/01/compare.py`（`PYTHONPATH=. uv run python lectures/01/compare.py`）。Codespaces ではなく手元の環境で実行した。
- 結果：

  | モデル | temperature | 出力トークン（3回） | 回答の傾向 |
  |---|---|---|---|
  | flash-lite | 既定 | 644 / 468 / 498 | 3回とも「AIエンジニア育成講座」と推測して、レベル分けの案を並べる |
  | flash | 既定 | 592 / 631 / 541 | 同じく推測。「課題の達成度・難易度」の分類として説明 |
  | flash-lite | 0.0 | 510 / 372 / 507 | 2回は推測、1回（372）は「情報を持っていない」という断りから始まる |
  | flash-lite | 1.5 | 525 / 467 / 488 | 推測。書き出しの言い回しが毎回少し違う |

  12回とも正解（基礎・実装・発展）にはならなかった。
- 気づき・疑問：
  - temperature 0 なら毎回同じ答えになると思っていたが、3回で長さも中身も変わり、1回は「知らない」という断りから始まった。0 にしても完全には固定されないらしい。評価するときは「1回試して良かった」では足りなくて、何回か回して分布を見る必要がありそう（講義の「100問中95問」の話につながる）。
  - モデルを flash に上げても、知らないことは知らないままで、もっともらしさが少し増しただけだった。講座固有の知識は、モデルを替えるより、資料を渡す側（第3回の用語集の検索など）で解決する話だと思う。
  - temperature 1.5 は、もっと崩れるかと思ったが、この質問ではほぼ差が分からなかった。
  - 実行中に 503（混雑）が何度か出たので、比較スクリプトには少し待って取り直す処理を入れた。無料枠だとこういうこともあるので、時間に余裕を持って回すのがよさそう。
